## 三、核心规则实现对照（对齐设计文档第 5、7 章）

### 3.1 回合与买断
- 常规最多 **5 回合**；第 5 回合若最高价并列，进入 **第 6 回合加赛**；加赛再次并列则 **流拍**。
- 买断倍数（第 1–4 回合，最高价 **严格大于** 第二名 × 倍数）：

| 回合 | 买断倍数 | 实现说明 |
| --- | --- | --- |
| 1 | > 2.0 倍 | 第 1 回合为「高于」而非「大于等于」，已用 `>` 严格判断 |
| 2 | > 1.6 倍 | |
| 3 | > 1.3 倍 | |
| 4 | > 1.1 倍 | |
| 5 | 不买断 | 价高者得 |

- 第 5 回合：最高价唯一者直接成交；并列则进入加赛。
- 第 6 回合：出价不得低于第 5 回合最高价；仍并列则流拍。

### 3.2 出价单调性（关键实现决策）
- 采用 **「当前叫价（standing bid）」** 模型：每位参拍者的最高出价跨回合保留且只增不减。
- 出价后不可撤销；玩家在某回合未出价/选择弃权即视为弃权，本局后续不再参与。
- 弃权后若仍有其他买家，系统会 **自动推演后续回合** 直至买断/成交/流拍，不会卡住流程。

### 3.3 结算与分红
```
玩家盈利 profit = 藏品真实总值 - 成交价 - 入场费
```
- 成交后买家获得全部藏品。
- 若买家亏损，其余玩家各获得 **亏损额的 10%** 分红；
  - 本地版中玩家为唯一真人：**当买家是机器人且亏损时，玩家获得 10% 分红**。
  - 帮手「观心·红利猎人」额外提升 50% 分红（即 15%）。
- 藏品处置：**出售**（立即变现）/ **入展**（放入展览柜，每场结算产出持续收益）。
- 展览柜收益按「每场结算一次」简化实现，未做真实时间挂机。

## 四、情报系统实现

| 来源 | 实现 |
| --- | --- |
| 公开情报 | 第 1、3、6 回合给出场地/规则提示文本 |
| 竞拍帮手（5 个，局前选 1） | 窥察师(轮廓) / 估价师(估值) / 鉴藏师(品质) / 仓储师(尺寸) / 红利猎人(分红+50%) |
| 仪器（局外购买，局内每回合限用 1 个） | 估值 / 轮廓 / 品质 / 低值排除 / 尺寸 |

- 未揭示藏品在界面以 `？` 呈现，仅通过情报逐步揭示轮廓、品质、尺寸、估值。
- 仪器：购买新组合会清空旧库存；未用完的仪器可在结算后 **带出** 留待下次。

## 五、AI 对手（对齐设计文档第 11 章）

每局生成 3 名机器人 + 玩家，共 4 人。机器人性格：

| 性格 | 特征 |
| --- | --- |
| 封闭式/商贾 | 保守，压低风险，早退 |
| 法眼·估价师 | 依据估值理性出价 |
| 狂飙·抬价客 | 激进抬价，可能触发买断 |
| 红利·渔翁 | 有意弃权，赚取买家亏损分红 |

- 机器人拥有私有估值（真实总值 × 噪声）与资金上限，按回合信心系数递增出价；
- 当叫价超过其承受上限时自动离场。
